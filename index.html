CONFIGURE ONCE

Ready before you need it

Owner registration is complete. Allow the simulated permissions, then send SETUP from the Recovery lab. SETUP syntax is a prototype convention because the specification does not name a setup keyword.

Command format

[exact password] [command] is represented by the two message fields. CONTACT accepts a name, for example CONTACT Taylor. The sender can be any fictional number.

Platform scope

Native Android SMS interception, background GPS, cell location, device administration, sound control and contacts access are simulated. Android version compatibility, carrier delivery, battery targets and actual response times require a native app and device testing. SMS suppression on newer Android remains an open requirement question.

OWNER ONLY

History and privacy

Configuration and history are encrypted in this browser using AES-GCM and a password-derived key. Locking the owner session clears the key and sensitive screen contents from the app’s memory. This is a classroom prototype, not a production security boundary.

Location history

Records older than 30 days are removed on login, activity, and a one-minute retention sweep while the owner session is open. Expired encrypted data can remain at rest while this page is closed, until the next successful login.

Command audit

Last 100 authenticated outcomes only; no raw command passwords, sender numbers or contact replies in the audit. Command messages are suppressed in the simulated native inbox.

Privacy controls

Contacts are fictional read-only fixtures. No contacts are imported from your phone. This app sends no command or configuration data to a server. Map links appear as text and are not fetched. Incoming queues and reply messages are held in memory only and cleared on session lock or reload.

RECORD THE FULL STORY

Your group demonstration

  1. Introduce the system and browser simulation. Each member says their name.
  2. Create owner access, review permissions, send SETUP and show its reply.
  3. Keep Internet off. Send LOCATE; disable GPS and repeat to show cell fallback. Turn the phone off, move it, queue LOCATE, then restore power to show the delayed execution timestamp. Last known is labeled with its capture time while the device is unreachable.
  4. Send SOUND ON from Silent. Send LOCK; try an incorrect PIN, then 2468.
  5. Send CONTACT Taylor, CONTACT Alex (up to three results), CONTACT Alez (close match), and CONTACT Nobody (not found).
  6. Send wrong and missing passwords. Show no new reply and no action. Try an unknown command; deny permissions and remove the native lock to show authenticated errors. Disable both location sources to show the location error.
  7. Show private history, retention cleanup, and audit. Lock owner access and show that data is hidden. Log back in to show encrypted persistence.
  8. Confirm every group member demonstrated a portion. Share the Teams recording with instructor and TA and verify both have viewing access before submission.

Unresolved source questions: SOUND OFF, dual SIM, backup, remote wipe, and Android SMS interception. They are not claimed as implemented features. “Set preview to Silent” is a testing control, not a SOUND OFF command.
